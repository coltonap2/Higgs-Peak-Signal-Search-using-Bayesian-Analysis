# Higgs Boson Rediscovery: Bayesian Inference and Discovery Sensitivity
## A statistical analysis for the $H \rightarrow ZZ^* \rightarrow 4 \ell$ Decay Channel

## Overview
This project performs a rediscovery of then Higgs boson using data for proton-proton collisions at the LHC from the CERN Open Data Portal; specifically, the data is 13TeV from Run 2 at the LHC from 2015-2018 and analyzes the four lepton ($4 \ell$) decay channel known as the "golden channel".
